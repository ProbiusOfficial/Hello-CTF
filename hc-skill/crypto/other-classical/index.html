其他形式的古典加密¶

CRYPTO · 知识域。换位、图案、符号类古典密码。标签:培根密码、栅栏密码、曲路密码、列移位加密、01248密码、猪圈密码。

触发特征¶

  • 密文字符集 = 明文字符集(换位不替换);或出现特殊符号/图形。
  • 提示"栅栏/云影/图案"。

培根密码¶

  • 5 位二进制(AAAAA-BBBAB)映射 26 字母;密文可以是任意"两种状态"(大小写、字体粗细、图片黑白块)。
  • 识别:串长是 5 的倍数且只有两种区分状态。

栅栏密码¶

  • 分组取位重组(Rail fence);栏数 2-8 全试即可(密钥空间极小)。
  • 变体:W 型、分组读法差异(常见工具实现不一致,两种读法都试)。

曲路密码¶

  • 约定路径填充矩形矩阵(蛇形/螺旋);行列数 + 路径方向需要枚举或从提示推断。

列移位加密¶

  • 密钥排序列号决定列读出顺序;已知列数暴力全排列(n≤8 可行),配合词频评分。
  • ADFGVX/ADFGX = Polybius + 列移位双层。

01248密码(云影密码)¶

  • 0 作分隔,组内数字和映射字母(1=A,2=B,...,8=H,8 表示 I-J 系);国内赛事特色题型。
  • 形如 8842101220... 的纯数字串即提示。

猪圈密码(Pigpen)¶

  • 符号网格映射字母;识别靠特殊符号形状(井字、X 形网格)。
  • 同族符号密码:圣堂武士(Templar)、摩斯/银河字母表,查表即解。

国内特色文字编码¶

  • 与佛论禅:中文佛经字符集与中文互映射(佛曰:… 开头),在线工具或对照表互转;变体:与熊论道、新佛曰。
  • 社会主义核心价值观编码:12 词对应 12 个状态对(富强/民主/文明/和谐…),两词一组解码为字节;核心价值观编码 工具直接转。
  • 舞动的小人:Sherlock Holmes 舞动小人符号密码(单表替换的图形版),对照表直查;同族:猪圈密码变体、天书/鸟篆类图形符号。
  • 识别共同点:密文是"看起来有意义的中文句子"(佛经/口号)或陌生图形符号 → 先查国内特色编码再怀疑真密码。

其他常见古典¶

  • 书本密码:页-行-列三元组,需拿到"书";Lorenz SZ40/42 历史机器(Historical 类);图灵式轮盘(reflector)。
  • 网格置换密码:5x5 行列独立置换,密钥空间 5!×5!=14400 可直接爆破(BSIDSSF 2026)。

工具速查¶

# 栅栏还原
def rail(ct, n):
    pattern = sorted(range(len(ct)), key=lambda i: (i % n, i // n))
    out = [''] * len(ct)
    for c, i in zip(ct, pattern): out[i] = c
    return ''.join(out)
