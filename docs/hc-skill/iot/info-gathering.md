# 信息搜集

> IOT · 知识域。设备侧侦察。标签:**设备信息搜集**、**固件信息搜集**、**协议分析**、**无线信号分析**。

## 触发特征

- 给一台真实设备/一个固件包/一段抓包,要求先建模。

## 设备信息搜集

- 硬件侦察:外观接口(UART/JTAG/SPI/I2C 排针)、丝印(主控 SoC 型号 → 数据手册)、Flash 芯片型号(容量/协议)。
- 开放服务面:nmap 全端口扫描(设备常开非常规端口:81/5555/8888);`nmap -sV --script vuln`。
- 云 APP 配套:拆 APP(→ [Reverse-Android](../reverse/android-reverse.md)) 找设备通信 API 与密钥。

## 固件信息搜集

- 版本识别:文件系统特征(/etc/版本文件、banner 字符串)→ 厂商型号确认 → 官方固件比对(找未修补漏洞)。
- 固件下载渠道:官网支持页、OTA 抓包(HTTPS 降级/证书校验缺陷时直接截获升级包)。

## 协议分析

- 设备通信抓包:Wireshark + 网络分流(集线器/镜像口);私有 TCP/UDP 协议结构还原(帧头/命令字/校验)。
- 串口抓包:UART 波特率枚举(逻辑分析仪);蓝牙 HCI log;Zigbee 抓包(KillerBee)。

## 无线信号分析

- 频谱侦察:RTL-SDR 找设备发射频点(→ [Misc-无线电信号分析](../misc/radio-signal.md) 全流程)。
- 遥控/传感器信号识别(OOK/FSK);配对流程观测。
