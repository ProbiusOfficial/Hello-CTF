# 键盘密码

> CRYPTO · 知识域。以键盘/手机按键布局为编码规则。标签:**手机键盘密码**、**电脑键盘棋盘加密**、**电脑键盘坐标加密**、**电脑键盘QWE加密**、**键盘布局加密**、**dvorak键盘加密**。

## 触发特征

- 密文全是数字且位数参差(手机九键);或字母位移呈键盘相邻关系。
- 提示"手机/键盘/九键"。

## 手机键盘密码

- 九宫格:数字=按键,重复次数=组内位置(`22`=B,`7777`=S);密文如 `22 777 444`。
- 多击编码进阶:DTMF 音频对应数字(→ [Misc-音频隐写](../misc/audio-stego.md));T9 预测输入(h4ckc0n 2017 变体)。

## 电脑键盘棋盘加密

- QWERTY 三行切成 3x10 网格 → 坐标(行,列)编码;数字串两两一组读坐标。
- 类 Polybius 思想,但"表"是键盘布局。

## 电脑键盘坐标加密

- 直接给出行列号对(如 `1-1 1-2`),按 QWERTY 布局查字母。

## 电脑键盘QWE加密

- 键位平移:明文字母用其**右边/左边**的键替代(Q↔W 系);解码反向查表。
- 识别:密文读起来像"所有手指都按歪了"的英文。

## 键盘布局加密

- AZERTY/注音/其他布局映射;拿到布局对照表逐键替换。

## dvorak键盘加密

- QWERTY 输入的按键按 Dvorak 解读(或反);常见于"输入法错位"型题目。
- 解法:两布局逐键对照表转换。
