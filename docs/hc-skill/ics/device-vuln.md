# 设备漏洞

> ICS · 知识域。工控设备本体漏洞。标签:**固件漏洞**、**默认密码**、**固件反编译**、**固件篡改**、**设备后门**、**设备越权访问**。

## 触发特征

- 目标为 PLC/RTU/网关/HMI 本体;要求设备级控制。

## 固件漏洞

- 固件获取与解包 → [IoT-固件分析](../iot/firmware.md) 全流程(工控设备固件多为 VxWorks/Linux/RTOS)。
- 历史高危:CVE-2016-2380(施耐德 Unity)、西门子固件签名绕过族、AB Firmware N-Day;shodan/fofa 指纹匹配后打。
- 嵌入式 Web/FTP/SSH 服务漏洞(设备管理面,→ [IoT-设备漏洞](../iot/device-vuln.md) 同源技术)。

## 默认密码

- 设备默认账户:西门子 admin/空、施耐德默认 USR/USR 族、SCADA 服务默认 SA 口令;厂商默认密码表。
- 协议层"默认无密码"(Modbus 全开)即广义默认配置(→ [网络通信](network.md))。

## 固件反编译

- VxWorks:符号表随固件携带 → IDA 直接恢复全部函数名;Linux 固件 → 常规流程。
- PLC 解释器层:IEC 61131-3 字节码(ST/LD/FBD 编译产物)反编译 → 还原梯形图逻辑。
- 加密固件(西门子部分型号):逆向升级器拿 key(→ [IoT-固件分析](../iot/firmware.md) 固件解密)。

## 固件篡改

- 修改固件内配置/逻辑后重打包(绕过签名校验,→ [IoT-固件分析](../iot/firmware.md) 签名验证)。
- 在线篡改:PUT/GET 写 PLC 内存(逻辑块直接替换)、在线下载工程覆盖。
- 持久化:固件级后门植入(重打包刷回)比运行时注入更顽固。

## 设备后门

- 已知后门:厂商调试后门(vxworks shell 魔法握手)、历史事件固件后门案例。
- 挖掘:字符串/魔法包分析、未公开端口服务指纹比对(与官方文档 diff)。

## 设备越权访问

- 工程接口越权:PLC Web 管理权限绕过(认证 cookie 伪造)、组态软件远程口令恢复(西门子工程口令离线解密)。
- 多级设备信任滥用:经网关/级联 PLC 横向到达隔离区设备。

## 转向

- 固件逆向细节 → [IoT-固件分析](../iot/firmware.md)/[Reverse](../reverse/index.md);拿到设备后改控制逻辑 → [逻辑漏洞](logic-vuln.md)
